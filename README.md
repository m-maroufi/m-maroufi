# 🌴 سلام، من مهدی معروفی هستم!

به دنیای برنامه‌نویسی و تکنولوژی علاقه زیادی دارم و همیشه سعی می‌کنم با یادگیری، تجربه و ساخت پروژه‌های جدید، دانش خودم رو گسترش بدم.
